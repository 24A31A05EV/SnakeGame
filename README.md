# 🐍 Snake Game

A classic Snake Game built from scratch using **Python** and **Pygame**.

The project uses a modular structure to keep the game logic, UI, settings, snake, and food systems separated and easy to maintain.

## 🎮 Features

- 🐍 Classic Snake gameplay
- 🍎 Random food generation
- 📊 Score tracking
- 🏆 High score tracking
- 💥 Wall collision detection
- 💥 Self-collision detection
- ⚡ Increasing game speed
- ⏸️ Pause and resume functionality
- 🔄 Restart after Game Over
- 🎮 Start menu
- ☠️ Game Over screen
- ⌨️ Arrow-key controls
- ⌨️ WASD controls
- 🕸️ Visual game grid
- 🧩 Modular Python architecture

## 🛠️ Technologies Used

- Python 3
- Pygame
- Git
- GitHub
